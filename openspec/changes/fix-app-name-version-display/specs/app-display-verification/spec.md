## ADDED Requirements

### Requirement: App name displays correctly in launcher
The application SHALL display "Curated Feeds" as the app name in the Android launcher.

#### Scenario: App name in launcher
- **WHEN** the APK is installed and viewed in Android launcher
- **THEN** the app displays "Curated Feeds" as the name

### Requirement: Version displays correctly in settings
The application SHALL display the version in the Settings screen.

#### Scenario: Version in settings
- **WHEN** user navigates to the Settings tab
- **THEN** the version is displayed (e.g., "1.0.0" or "1.0.0+1")
